# SouyanDev's Birthday Countdown

This is a simple countdown timer for SouyanDev's birthday. It displays the countdown in a user-friendly and visually appealing way.

## Features

-   Simple and user-friendly countdown timer
-   Visually appealing design
-   Customizable colors and fonts
-   Copyable link
-   Confetti animation on birthday celebration

View the live demo [here](https://souyandev.github.io/birthday/).
